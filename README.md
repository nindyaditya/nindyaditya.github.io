# Nindy Portfolio

A Framer-independent static portfolio, rebuilt from `https://nindyadit.com` on August 31, 2026. All application code, images, and fonts are stored in this repository.

## Structure

- `index.html` for the homepage
- `projects/ecoflow/index.html`
- `projects/dunia-games/index.html`
- `projects/my-grapari/index.html`
- `projects/byu/index.html`
- `404.html`

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Open `Settings > Pages`.
3. Set the source to `Deploy from a branch`.
4. Choose your default branch and `/ (root)`.

No Framer runtime or Framer-hosted assets are required to deploy this site.
